# UI Revision 9 — restore Revision 6 styling

Based on Revision 8, with the **exact Qt Fusion palette functions and Light / Dark graphite selection from Revision 6**. Removed the ICOCR stylesheet including square button corners, tab customizations, and extra themes.

- Settings > Appearance: Light, Dark graphite (Revision 6 appearance).
- Existing optional dark-mode pinout inversion is preserved.
- Revision 7/8 group management, editable component tables, sortable columns, editor, and pinout preview remain unchanged.
- Saved unsupported theme values fall back to Light.

The original database schema and backend are unchanged. Graphical operation on Windows was not tested.
