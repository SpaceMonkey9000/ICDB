# ICDB Qt UI Revision 18 — Components Columns / Light Grid

- Main Components table shows Part number, Function and Pinouts only.
- Manufacturer remains stored, searchable, shown in details, and editable in the Add Device dialog.
- Adjusted inline editor column mapping so Pinouts is read-only.
- Light theme now uses a very faint (#ECECEC) gridline throughout QTableView-based tables (including dynamic dialogs), with subtle palette separators.
- Dark theme retains the Revision 17 styling.
- No database schema or transactional editing changes.
