# ICDB PySide6 UI Revision 10

Baseline: Revision 9 (Revision 6 Fusion appearance, Light and Dark Graphite palettes).

## Changes

- Windows 10/11 native title bars request dark immersive mode through DWM. Qt Fusion window contents and rounded native-style controls remain unchanged. Other platforms fall back to OS title bars.
- Settings > Tools: SVG publishing/rebuild controls. Choose incremental publication (only changed content) or forced regeneration, and view rendered/updated/removed/skipped counts. Requires saving or reverting current pinout edits first. This operation modifies shared published reference assets and database links.
- Import tab: choose and preview supported pinout sources (master/grouped DB, KiCad symbols, ICPin JSON/catalog, bundles, pin-table CSV), optional device CSV mapping, then confirm importing via the existing Library import backend. Includes import history and unresolved-conflict summary. No SVGs generated by importing. Matching tab remains excluded.
- Import and rebuild work runs on a separate QThread with its own SQLite connection. Only one background database operation at a time; closing the window is blocked until it finishes.

## Important limitations

- Import does not include the old application's interactive source-conflict resolution window. Conflicts are retained and visible in Import history for later review.
- The Windows title-bar API is supported on modern Windows builds and can be ignored by older Windows versions or system policy. Qt palette alone cannot change native Windows title bars.
- Live Windows Qt execution remains unverified in this environment.
